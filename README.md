# 🖼️ Wallpaper Download Web Application

A dynamic and responsive Wallpaper Web Application built with HTML5, CSS3, JavaScript, and Firebase Authentication.

## ✨ Features
- 🔐 **User Authentication:** Firebase Auth integration for seamless Login/Logout functionality.
- 👑 **Dynamic UI Rendering:** VIP Badge, Email Display, and Premium Wallpapers Unlocked status upon user login.
- ⏱️ **Guest Interactive Pop-up:** Intelligent 3-second modal prompt encouraging non-logged users to sign in.
- 📱 **Responsive Design:** Clean grid view for wallpaper showcase across mobile and desktop devices.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Backend Services:** Firebase Authentication
